# 일본 소설

일본 고전소설을 한국어로 읽을 수 있도록 정리한 폴더입니다.

## 작품

- [겐지 이야기 완역본](genji-complete/README.md) — 현대 한국어로 옮기는 54첩 장별 완역본
- [겐지 이야기 축약본](genji-monogatari.md) — 54첩의 전체 줄거리를 잇는 한국어 축약 산문본

## 편집 원칙

- 현대 번역본을 옮기지 않고, 저작권이 만료된 고전 원작의 사건과 인물 관계를 바탕으로 새롭게 서술합니다.
- 원전의 54첩 순서와 일본어 제목을 유지합니다.
- 원문의 와카는 특정 번역을 인용하지 않고 의미와 정서만 산문으로 풀어 씁니다.
- 인물에게 고정된 이름이 드문 원작의 특성을 따라 관직·거처·통칭을 함께 사용합니다.
