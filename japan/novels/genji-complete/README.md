# 겐지 이야기 현대 한국어 완역본

무라사키 시키부의 『겐지 이야기』 54첩을 현대 한국어로 옮기는 완역본이다. 각 첩을 별도 파일로 작성하고 원문의 장면, 대화, 편지와 와카를 생략하지 않는 것을 원칙으로 한다.

## 번역 원칙

- 고전 원문의 내용과 서술 순서를 보존하되 한국어 문장은 자연스러운 현대 문학어로 쓴다.
- 원문에서 이름을 직접 부르지 않는 인물은 통용되는 호칭으로 표기한다.
- 관직과 궁중 제도는 첫 등장 때 문맥 안에서 뜻을 밝혀 읽는 흐름을 해치지 않게 한다.
- 와카는 직역보다 이미지와 중의성을 살린 한국어 시로 옮기고 필요한 경우 짧은 역주를 붙인다.
- 특정 현대 한국어 번역을 참조하거나 전재하지 않는다.

## 저본과 대조 자료

- 원문 대조: 일본 국립국어연구소 공개 미국 의회도서관 소장본 전사 자료
- 문장 해석 대조: 아오조라문고 공개 요사노 아키코 현대어역
- 제41~54첩 초고의 1차 대조에는 각 첩에 링크한 고전 원문·요사노역 병렬 자료와 아오조라문고 공개본을 사용했다. 병렬 자료의 별도 현대어역은 번역 저본으로 사용하지 않았다.
